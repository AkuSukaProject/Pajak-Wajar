# Sistem Desain PajakWajar

Sumber palet: referensi visual yang diberikan Mikail pada 29 Agustus 2026.

| Token | Nilai | Peran |
|---|---:|---|
| Kertas HVS | `#F4F6F8` | Latar aplikasi |
| Tinta | `#14202E` | Teks dan struktur utama |
| Biru sah | `#17497D` | Tindakan utama dan status berhak |
| Merah stempel | `#A32E28` | Status tidak berhak dan galat |
| Oker meterai | `#7A5C15` | Status perlu dipastikan dan peringatan |
| Abu margin | `#5E6B7A` | Teks pendamping dan sitasi |

Status tidak dibedakan dengan warna saja: masing-masing memakai simbol, label tertulis, dan bentuk penanda yang berbeda. Tipografi memakai Newsreader untuk judul/vonis dan Libre Franklin untuk isi. Arah visual mengambil bahasa dokumen hukum—lembar, nomor perkara, sitasi, dan stempel—tanpa meniru estetika fintech.
